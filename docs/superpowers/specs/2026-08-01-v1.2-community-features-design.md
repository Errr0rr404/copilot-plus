## Architecture

Pure modules under `src/` + thin glue in `wrapper.js` / `bin/copilot+` / `config.js`. Matches v1.1 pattern.

| Module | Responsibility |
|--------|----------------|
| `workflows.js` | YAML/JSON multi-step prompt chains |
| `notify-rules.js` | Rule evaluation + OS/bell/webhook channels |
| `config-share.js` | Export/import shareable config package |
| `prompt-stash.js` | Stash/pop draft prompt stack |
| `prompt-queue.js` | Pending prompts while agent busy |
| `usage-meter.js` | Local usage stats + daily burn + quota alerts |
| `file-picker.js` | Fuzzy file list for `@path` inject |
| `worktree.js` | `git worktree add` + launch helper |
| `handoff.js` | Limit handoff markdown snapshots |

## Hotkeys

| Key | Action |
|-----|--------|
| Ctrl+E | Open last response in `$EDITOR` |
| Ctrl+S | Stash current input line |
| Ctrl+O | File picker → inject `@path` |
| Enter (while awaiting response) | Enqueue prompt if `queue.whenBusy` |

## Config additions

```json
{
  "queue": { "whenBusy": true, "maxSize": 20 },
  "notifications": {
    "quiet": false,
    "sound": false,
    "webhookUrl": "",
    "rules": [
      { "when": "session_idle", "channels": ["os"] },
      { "when": "waiting_input", "afterMs": 60000, "channels": ["os", "bell"] },
      { "when": "quota_above", "pct": 80, "channels": ["os"] }
    ]
  },
  "usage": { "dailyBudget": 0, "handoffAtPct": 90 },
  "workflowsDir": ""
}
```
